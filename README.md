AI-Powered Packaging Chatbot – Week 3 Project | PackPro Solutions. For my Week 3 project, I built a simple AI-powered chatbot for a fictional emerging packaging company called PackPro Solutions. The purpose of this chatbot is to help customers get quick answers to common packaging-related questions such as products, materials, minimum order quantity (MOQ), customization, samples, production time, delivery and quotations. I developed the project using Python in Google Colab. The chatbot uses a small knowledge base stored in packaging_knowledge.json, which contains packaging-related questions and answers. To match customer questions with the knowledge base, I used TF-IDF, Cosine Similarity and Scikit-learn. The chatbot compares the customer's question with the stored questions and provides the closest suitable answer. I also added a similarity threshold so that when a question does not match the knowledge base well enough, the chatbot gives a fallback response instead of providing unrelated information. The chatbot also includes a quotation feature. When the user types "quote", it collects details such as product type, dimensions, quantity, material, printing, finishing and delivery city. These quotation details can be saved in quote_requests.json. I also added conversation logging, which stores customer questions and chatbot responses in conversation_log.json. I tested the chatbot with different questions about MOQ, materials, custom boxes, logo printing, samples, production time and delivery. I also tested empty inputs, unrelated questions, numbers, extra punctuation and different ways of asking the same question. During testing, I added input checking and a similarity threshold to improve the chatbot's responses. The main files of this project are AI_Packaging_Chatbot_Week3.ipynb, packaging_knowledge.json, quote_requests.json, conversation_log.json, README.md, PROJECT_REPORT.md and CHANGELOG.md. The main tools used are Python, Google Colab, Pandas, Scikit-learn and JSON. This project is different from my previous projects because Week 1 focused on AI sales forecasting for a logistics startup and Week 2 focused on an AI-assisted website quality auditor for accounting websites, while this Week 3 project focuses on conversational AI and customer support for a packaging company. Through this project, I learned how to create a domain-specific knowledge base, process user questions, use TF-IDF and Cosine Similarity, handle unknown questions, collect quotation information and test a chatbot. This is a working prototype that can be improved in the future by adding a web interface, more packaging information, multilingual support, automatic price estimation, a real company database, CRM integration and human support.
